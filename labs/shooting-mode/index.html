Shooting mode

A playful browsing mode where Ludwigia feels less like a document archive and more like a stylized mission space: scanning targets, picking routes, and surfacing content through action-oriented UI.

mock first 3D later HUD-inspired Labs-only
What this page is for

Lock down the fantasy, the interaction loop, and the IA bridge before investing in a full shooter implementation.

Open laser-tag page Back to Labs

Core loop

Pick a mode, acquire a target, then move through content as if progressing through a compact mission.

  • Entry feels intentional, not just decorative
  • Targets map to notes, writing, projects, or companions

UI language

Use HUD-like framing, strong wayfinding, and quick state cues without forcing the whole experience into a game immediately.

  • Crosshair / radar motifs can stay as lightweight layout cues
  • Readable cards still win over pure spectacle

IA bridge

Labs owns the experiment, while the main site keeps a stable document-first information architecture.

  • No need to replace Search, Garden, or Portfolio yet
  • Use Labs as the safe place to test mode switching

First deliverable

Keep it as a concept page with a few concrete mode states instead of starting with physics, networking, or combat simulation.

  • State 1: choose an entry fantasy
  • State 2: preview a target and why it matters
  • State 3: jump into the existing content page

Prototype bridges

Two future directions already exist and can be treated as technical or mood references instead of immediate product commitments.

  • Massive multiplayer laser tag for shooter mechanics and HUD energy (Work in Progress)
  • Cosmic flow for ambient motion and softer interaction pacing (Work in Progress)
