物理筆記總整理

直線運動

等加速直線運動 等加速度運動中，物體的速度與時間成線性關係。 位移公式： s = v0t + 1/2 a t² v² = v0² + 2as 平均速度 = (v + v0) / 2 等加速度運動時，第 t/2 秒瞬時速度 = t 秒內平均速度。 若初速為零，位移與時間平方成正比。

自由落體運動 自由落體為等加速度運動，a = g = 9.8 m/s²。 速度：v = gt 位移：s = 1/2 gt² 時間與速度及位移皆成正比關係。

平面運動 平面運動可分解為互相垂直的兩個直線運動。 例如拋體運動：水平方向為等速運動，垂直方向為等加速度運動。 位移可由向量合成，合速度大小 v = √(vx² + vy²)。

靜力學

重心與質心 重心為物體受重力作用的平衡點。 質心為物體質量分佈的平衡位置。 對均勻物體，重心與質心重合。 若物體傾斜到重心超出支點時，物體將翻倒。 臨界條件：tanθ = x/y 時物體開始翻倒，其中 x 為重心水平距離，y 為支點高度。

平衡條件 物體處於靜止或等速運動時，合力與合力矩皆為零。 ΣF = 0，Στ = 0。

牛頓運動定律

第一運動定律（慣性定律） 若無外力作用，物體保持靜止或等速直線運動狀態。 慣性大小與質量成正比。

第二運動定律（加速度定律） 物體所受外力與其加速度成正比，方向相同。 公式：F = ma。 單位：牛頓（N）。

第三運動定律（作用反作用定律） 每個作用力必有大小相等、方向相反的反作用力。 作用力與反作用力作用在不同物體上。

摩擦力 靜摩擦力：防止物體相對運動，最大靜摩擦力 f_s(max) = μ_s N。 滑動摩擦力：f_k = μ_k N，方向與運動方向相反。 通常 μ_s > μ_k。 若物體恰好滑動又同時翻倒，則靜摩擦係數 μ_s = tanθ = x/y。 摩擦力不影響牛頓第三定律的成立。

動量守恆與系統質心運動

動量與衝量 動量：p = mv。 衝量：I = Ft = Δp。 平均衝力 × 作用時間 = 動量變化。 平均衝力 = 平均力，瞬時衝力 = 瞬時力。 若淨外力為零，系統總動量守恆。

動量守恆律 封閉系統中，若外力合為零，則 Σp_before = Σp_after。 適用於碰撞、爆炸等過程。 系統質心運動遵守：M V_cm = Σmi vi。

碰撞 一維碰撞： 彈性碰撞：動量與動能皆守恆。 非彈性碰撞：僅動量守恆，部分動能轉為熱或形變能。

一維彈性碰撞公式： v1' = (m1 - m2)/(m1 + m2) v1 + (2m2)/(m1 + m2) v2 v2' = (2m1)/(m1 + m2) v1 + (m2 - m1)/(m1 + m2) v2 相對速度關係：v1 - v2 = -(v1' - v2')。

非彈性碰撞： 完全非彈性碰撞中，兩物體黏在一起，v' = (m1v1 + m2v2)/(m1 + m2)。 動能損失最大。

系統質心運動 系統質心速度：V_cm = Σmi vi / Σmi。 若外力合為零，質心作等速運動。 系統內部力不改變質心運動狀態。

電流與歐姆定律

電流 電流 I = Q / t。 方向定義為正電荷流動方向。 單位：安培（A）。

電阻與歐姆定律 符合歐姆定律之導體在固定溫度下，I 與 V 成正比。 V = IR，其中 R 為電阻。 電阻受材料、長度與截面積影響，R = ρL / A。 溫度升高時，大多數金屬電阻增大。 電阻率 ρ 取決於材料性質。

功率與能量 電功率：P = IV = I²R = V²/R。 電能：W = Pt。 效率 = 輸出功 / 輸入能量。

電流的磁效應

磁場與洛倫茲力 通電導線產生磁場，方向依右手定則判定。 帶電粒子在磁場中受力：F = qvB sinθ。 力方向依右手定則（v × B）。 帶電粒子若垂直進入磁場，將作勻速圓周運動： qvB = mv²/r → r = mv / qB。 圓周運動週期 T = 2πm / qB，與速度無關。 若帶電粒子斜射入磁場，將作螺旋運動。

磁場對電流的作用 通電導線在磁場中受力：F = BIL sinθ。 方向依右手定則：四指為電流方向，磁場方向為掌心指向，拇指為力方向。 平行導線間若電流同向則互吸，反向則互斥。

電流與磁場的關係 磁通量 Φ = BA cosθ。 電磁感應定律：感應電動勢 E = - dΦ/dt。 楞次定律：感應電流方向總是反抗磁通量的變化。 右手定則：磁場→手掌方向，四指為導線移動方向，拇指指感應電流方向。

直線運動 可用位移、速度、加速度三式互推。 注意方向設定與正負號。

靜力學 判斷重心位置是否在支點垂直線內。 分析翻倒或滑動條件。

牛頓運動定律 畫受力圖，分析合力方向。 若加速度為零，物體處於靜力平衡。

摩擦力 先確定物體是否滑動，靜摩擦力為可變力，滑動摩擦力為定值。

動量守恆 若外力為零則可用動量守恆。 彈性碰撞需同時滿足動量與動能守恆。 完全非彈性碰撞動能損失最大。

電流與磁效應 電流方向與磁場方向的相互關係可用右手定則判定。 帶電粒子在磁場中的運動路徑為圓或螺旋。
