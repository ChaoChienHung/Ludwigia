SpaceshipX

SpaceshipX is a small assembly-based game developed using MASM and WinDbg. In the game, the player controls a spaceship to shoot bullets and destroy incoming comets to protect Earth. Future updates will include new items, additional weapon types, and extra lives.

Key Features

  • Control the spaceship using the keyboard: arrow keys (W, S, A, D) to move, and Space to shoot.
  • Shoot bullets to destroy incoming comets
  • Protect the Earth from destruction
  • Score tracking based on destroyed comets
  • Game over condition when a comet hits the Earth

Planned enhancements

  • Add new items such as power-ups and shields
  • Introduce additional weapon types
  • Implement extra lives for the player

Ludwigia

Ludwigia is my personal website that serves as both a portfolio and a playground for learning essential web development skills. Through this project, I practice core frontend technologies such as HTML, CSS, JavaScript, and Bootstrap while building a space to introduce myself and showcase my work.

Key Features

  • Projects page featuring a carousel preview of selected work
  • Garden section for a personal note library
  • Writing section for longer, evolving thoughts

Planned enhancements

  • Responsive layout for smartphones and tablets
  • Garden & Writing expansion

Karen

Karen is my personal LLM lab for experimenting with both pretrained fine-tuning and scratch-built mini models under one training workflow. The repo shares a single dataset pipeline across HuggingFace + LoRA runs and lightweight GPT2/Llama variants, with every run recorded under a consistent output layout.

Key Features

  • Unified training entrypoint via python -m llm.train with --arch and --engine
  • Pretrained fine-tuning path with HuggingFace, LoRA, and optional 8-bit loading
  • Scratch GPT2 and Llama-style mini models for faster architecture experiments
  • Traceable runs/<run_name>/ outputs for args, env, logs, metrics, and checkpoints

Project Scope

  • Training and evaluation entrypoints for local or multi-GPU workflows
  • Reusable preprocessing, logging, and model packaging utilities
  • Benchmark recipes and experiment logs documented alongside the codebase

Mentorion

Mentorion is a learning support project built to practice LLM integration while turning articles into study material. Its FastAPI backend scrapes or parses content into structured notes, then generates question-and-answer pairs that can be consumed from either a React web app or a Streamlit interface.

Key Features

  • Scrape articles from URLs into note objects
  • Parse raw content into structured notes
  • Generate question-and-answer sets from stored notes
  • Ship both React/Vite and Streamlit frontends on top of the same backend

Project Scope

  • FastAPI API under /api/v1 for scrape, parse, and question generation flows
  • Gemini-powered note generation and QA workflows driven by environment configuration
  • Backend tests plus separate UI surfaces for iterative product experiments

Detox.io

Detox.io is a comment detoxification system that detects harmful language and rewrites it into socially acceptable wording without losing the original context and intent. The runtime supports pluggable toxicity detection and detoxification backends, while its training workflows are intentionally split into the Sesame and Karen toolchains.

Key Features

  • Detect toxic comments with classifier, OpenAI, or local LLM backends
  • Rewrite toxic comments while preserving the source meaning
  • Use retry and fallback logic to keep detoxification flows resilient
  • Log key runtime events and support environment-driven backend switching

Project Scope

  • Standalone inference pipeline in main.py for detection plus rewriting
  • Training and evaluation documentation for Sesame and Karen submodules
  • Architecture, API, privacy, and safety notes maintained in project docs

PiggyNest

PiggyNest is a full-stack personal finance and asset management app built with FastAPI and React. It models real-world money flows through PiggyBanks, then layers transactions, transfers, reports, and analytics on top of a multi-currency setup.

Key Features

  • JWT-based authentication for user registration and login
  • Multi-currency PiggyBanks as separate wallets or sub-accounts
  • Transaction recording, category management, and inter-bank transfers
  • Reports, statistics, charts, and CSV import/export flows

Project Scope

  • FastAPI backend with SQLite plus a React/Vite frontend
  • Dashboard analytics and period-based financial summaries
  • Developer CLI for API self-testing and lightweight DB inspection

Scriba

Scriba is a sandbox for building, training, and evaluating handwritten text parsing models while also supporting real application surfaces. The project compares OCR and structured parsing approaches such as TrOCR and Donut, then exposes them through CLI, API, and web interfaces.

Key Features

  • Model baselines for handwritten OCR and structured document parsing
  • Unified training and evaluation entrypoints for multiple architectures
  • CLI inference plus FastAPI and Next.js application surfaces
  • Karen-style run and model layout for reproducible experiments

Project Scope

  • Support TrOCR and Donut workflows from dataset setup to evaluation
  • Publish default checkpoints through the local models/<arch>/latest structure
  • Keep experiment notes, compatibility rules, and workflows in project docs

Sesame

Sesame is a BERT-family training lab that adapts Karen's repository conventions into a workflow for BERT, RoBERTa, and related architectures. It focuses on a unified training entrypoint, task and model registries, and a stable run-output structure that can be reused by downstream projects such as Detox.io.

Key Features

  • Unified python3 -m bert.train interface across tasks, models, and engines
  • Registry-based architecture for BERT-family models and tasks
  • Support for masked language modeling and multi-label classification workflows
  • Structured runs/<run_name>/ outputs plus dedicated evaluation scripts

Project Scope

  • Reusable preprocessing and split utilities shared across tasks
  • Trainer and custom-loop execution modes for experimentation
  • Alignment with Detox.io toxic-comment classification use cases

Vellichor

Vellichor is an offline-first diary app backed by local SQLite, with entry content encrypted before it is stored. It offers both a local web interface and a CLI workflow, using password-derived keys and encrypted content fields to keep journaling private by default.

Key Features

  • Offline-first journal with local web and CLI interfaces
  • SQLite as the single source of truth for metadata and encrypted entry storage
  • Password-derived encryption flow with AES-based content protection
  • Entry creation, listing, search, and password rotation workflows

Project Scope

  • Local-first workflow that does not depend on a remote backend
  • MVP search over decrypted local previews with room for future indexing work
  • Documentation around security, setup, and operational usage for the project
