# Hill Climb

An external Agent skill by Lennox Saint for long jobs with a measurable target. It uses a locked answer key, fresh agent sessions, and independent judges to decide whether the target has been met. The upstream repository reports runner checks, but no real-work benchmark yet. It requires Node, git, and a compatible agent CLI; see the original skill for platform details.

For the complete workflow, requirements, and installation steps, use the original Skill. This Toolkit entry is a short guide and source link, not an installed copy.
