# Loop

An external Agent skill by Lennox Saint for improving one draft. It defines a 100-point rubric, revises the artifact, and reports unmet criteria. Its published cold run used self-scoring, so treat the score as an editing aid rather than independent evidence of quality.

For the complete workflow, requirements, and installation steps, use the original Skill. This Toolkit entry is a short guide and source link, not an installed copy.

Reference: https://github.com/lennoxsaint/Skills/tree/main/loop
