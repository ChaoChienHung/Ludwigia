# Adversarial Review

An external Agent skill by Lennox Saint for important drafts, plans, or implementation decisions. A separate reviewer challenges the work; the working Agent checks each finding against the actual artifact, fixes supported issues, and reports unresolved points. A reviewer score is feedback, not proof that the work is correct.

Use the upstream skill when an independent review is available and the cost of a missed flaw justifies another pass. This entry is a pointer and summary, not a local copy of the skill or its review tools.
