# Claude Conductor

An external Agent skill by Lennox Saint for users with multiple Claude Code sessions. It reviews open sessions, prioritizes them against the user's goals, and follows work to a verified stopping point. It depends on Claude Code and a way to inspect those sessions; it is not a generic multi-agent manager.

For the complete workflow, requirements, and installation steps, use the original Skill. This Toolkit entry is a short guide and source link, not an installed copy.
