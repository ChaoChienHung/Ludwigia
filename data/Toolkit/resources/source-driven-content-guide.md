# Source-driven content checklist

Use this checklist when a site turns Markdown or structured data into public pages.

1. Decide which file the author edits. Keep metadata and body in that source.
2. Generate the HTML and browse index from the source. Never require a second manual title, tag list, or summary.
3. Mark drafts explicitly and exclude them from public discovery while keeping a local preview route.
4. Keep links and assets valid when an article lives several directories deep.
5. Check whether copy and download actions preserve the core text without private authoring notes.
6. Make the build repeatable: unchanged source should yield the same output.
7. After a schema or navigation change, regenerate representative pages and the public index, then review on desktop and mobile.

This is a reusable summary of Ludwigia's `AGENTS.md` and `README.md` workflows. Consult those original files for the site's exact rules.
