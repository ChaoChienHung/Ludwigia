# Strategy Prompt

An external Agent skill by Lennox Saint for decisions with several plausible options. It asks for the user's context, a fair case for each option, explicit decision criteria and weights, a checked scoring calculation, and a challenge to the first recommendation. Directional scores should remain clearly labeled as judgments rather than measured facts.

Use the upstream skill when a structured comparison would clarify a real decision. This Toolkit entry summarizes the use case; the original skill contains the full procedure.

Reference: https://github.com/lennoxsaint/Skills/tree/main/strategy-prompt
