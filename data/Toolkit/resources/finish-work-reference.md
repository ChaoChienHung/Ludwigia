# Finish Work

An external Agent skill by Lennox Saint. Use it when a substantial task is nearing completion or stopping early. It asks the Agent to check the result through the relevant real entry point, distinguish local changes from published outcomes, and report what remains unverified. The upstream skill also includes a receipt helper; this Toolkit entry does not include or run that helper.

For the full workflow, requirements, examples, and installation instructions, follow the original skill. Its checks and receipts complement a project's `HANDOFF.md`: a handoff records the latest stopping point, while a receipt records evidence for a particular task.

Reference: https://github.com/lennoxsaint/Skills/tree/main/finish-work
