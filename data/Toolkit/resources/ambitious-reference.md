# Ambitious

An external Agent skill by Lennox Saint for work the user explicitly marks as important or high stakes. It turns the intended outcome into measurable targets, works from real source material, checks the finished artifact, and seeks an independent judgment where available. The upstream workflow takes more time and tools than a routine task.

Use the original skill and its installation guide if this level of review fits the task. This Toolkit entry is a pointer, not an installed copy or a claim that its evaluation results apply to this site.
